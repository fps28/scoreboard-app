ТАБЛО — комплект для публикации

Что внутри:
- index.html — интерфейс
- app.js — логика и сохранение данных в браузере
- manifest.json — метаданные для установки на телефон как PWA
- sw.js — кеш для офлайн-открытия
- icon.svg — значок

Публикация через GitHub Pages (бесплатно):
1. Создайте аккаунт на github.com (если ещё нет).
2. Создайте новый репозиторий, например scoreboard-app.
3. Загрузите ВСЕ файлы из папки комплекта в репозиторий (в корень).
4. На GitHub откройте Settings -> Pages.
5. В Source выберите Deploy from a branch.
6. Branch: main, Folder: / (root), Save.
7. Подождите несколько минут. GitHub покажет ссылку вида https://ВАШ-АККАУНТ.github.io/scoreboard-app/
8. Откройте ссылку на телефоне. В меню браузера выберите «Добавить на главный экран» / «Установить».

Важно:
- Данные пока хранятся локально на конкретном устройстве и браузере.
- Не очищайте данные сайта, иначе записи могут потеряться.
- Это простая версия без аккаунтов и синхронизации между устройствами.
